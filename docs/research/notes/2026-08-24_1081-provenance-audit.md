# Provenance Audit — July Research Cluster (GH #1081, Step 1)

**Date**: 2026-08-24
**Author**: quant-researcher
**Type**: Step 1 only — provenance audit from the record (branch/commit history, in-doc command

**Scope**: the document list from GH #1081, in the PM's priority order.

## Method

For every document I established: (a) which worktree/branch/commit it ran from, if declared;
(b) whether numbers were **executed** (backtest/train) or merely **read** (code, DB query); (c)
for executed numbers, which invocation shape was used (`atb <cmd>` console script,
`python experiments/*.py` / other script path, `python -c`, or an in-process import), since only
two of those shapes are actually vulnerable to GH #1070 per the fix commit
(`acb36b74`, `#1080`) — the stale `sys.meta_path` mapping only loses when a `sys.path` entry
*already* contains `src`/`cli` before import, which is true for `python -c` and a script located
at the repo root, and false for the `atb` console script and `python experiments/*.py`; (d) for
scripts, whether they explicitly manipulate `sys.path`/`PYTHONPATH` to defeat the bug; (e) the
date, checked against two cutoffs:

- **2026-07-04 15:35:32** (`20788b72`) — the primary checkout's frozen `main` HEAD. Confirmed via
  `git log -1` on the primary checkout's `main` ref.
- **2026-08-13 19:23** — the informal mitigation shim GH #1081 cites as installed same-evening as
  the #1070 discovery ([D-2026-08-13-06], 18:15). This predates the robust fix (`verify_source_root()`
  hard guard + `tools/atb_worktree_shim.py`, merged 2026-08-24 10:48 via `#1080`) by 11 days. The
  interim shim is **not** covered by any hard-fail guard — a venv rebuild would have silently
  dropped it with no error — so I treat anything in the 08-13→08-24 window as lower-confidence-safe
  than anything after `#1080` landed, not unconditionally clean, unless the document itself shows
  runtime provenance evidence (e.g. a printed `src.__file__` / git-rev banner).

For documents with a declared worktree branch-point commit, I diffed that commit against the
frozen `main` HEAD on the specific files the experiment depends on (`src/engines/`,
`src/strategies/`, `cli/commands/backtest.py`, `src/risk/`) to determine whether misdirection to
the primary checkout would have changed the answer, not just the label.
